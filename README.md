# CS50 – Birthdays

## Description

This project is a web application created as part of CS50x's Birthdays problem set.

The goal of the exercise was to build a Flask application that allows users to add, view, and remove birthday records using a SQLite database. The project introduces server-side programming, form handling, database interaction, and template rendering with Flask.

## Features

- Add new birthday records through an HTML form
- Store and retrieve data using a SQLite database
- Display database records dynamically
- Remove existing entries
- Validate user input before storing data

## Technologies

- Python
- Flask
- SQLite
- HTML5
- Jinja templates

## Concepts

- Web application structure with Flask
- HTTP GET and POST requests
- Form handling and input validation
- Database queries and CRUD operations
- Server-side rendering with Jinja
